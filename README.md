# BookNest - Interactive Online Bookstore

A simple online bookstore website built with HTML, CSS and JavaScript

Live demo: https://YOUR-USERNAME.github.io/online-bookstore/

## Features
- Home page with featured books, categories and search
- User registration and login with JavaScript validation
- User profile page with edit option
- Books catalog with search and category filter
- Shopping cart (increase/decrease quantity, remove, dynamic total)
- Credit card payment form with validation (simulated, no real payment)
- Order confirmation page with order ID, items, total and date

## How to Run
1. Download or clone this repository
2. Open `index.html` in any web browser
3. Register a new account, log in, add books to the cart and checkout

Note: Data is saved in the browser's localStorage, so you must
register before logging in.
